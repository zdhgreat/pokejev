## 各版本配对评测（v0.2）

- **队伍：** 72 组固定队伍，由 Pokémon Showdown 自带的随机对战生成器用固定种子生成。
- **座位：** 每组队伍交换座位各打一局（每个版本 144 局）。
- **设置：** 对战格式为 `gen9customgame`，对手是 poke-env 的 `SimpleHeuristicsPlayer`；所有版本打同样的对局，所以差异是配对比较。
- **置信区间：** 按队伍组做 bootstrap，取 95% 区间。

| 版本 | 胜局 / 144 | 相对 v0.1 |
|---|---|---|
| v01 | 80（56%） | — |
| v1：+ 太晶化 + 计算器 | 93（65%） | +9.0 [0.0, 18.8] |
| v2：+ 下一回合事实 | 94（65%） | +9.7 [−1.4, 20.8] |
| v3：+ 两阶段候选 | 91（63%） | +7.6 [−4.2, 18.8] |
| **v4：v2 + 记忆** | **100（69%）** | **+13.9 [4.9, 23.6]** |

- **提升来源：** 主要来自太晶化和计算器（更好的事实）。两阶段候选的成本翻倍，却没有带来收益。
- **配对的局限：** 服务器的对战随机数没有固定种子，所以配对只控制了队伍抽取，没有控制对战中的运气。

## 意图操控（实战，v0.1 智能体）

| 意图 | 冲突回合 | 遵从 |
|---|---|---|
| 同一招式不连用 3 次 | 35 | 100% |
| 除非能击倒，不连续使用同一招式 2 次以上 | 71 | 99% |
| 除非能击倒，不使用降自身能力的招式 | 79 | 100% |
| 有 ≥1 倍效果的其他攻击招式时，避免命中率低于 85% 的招式 | 43 | 91% |

非冲突回合误破坏：0.4%。胜局：104 / 200（52%），不加意图的规则为 54 / 100（54%）。

## 与其他公开 Jev 智能体正面对战（v0.1，各方均为 `jev-1.13.0`）

| 对手 | 结果（我方在前） | 说明 |
|---|---|---|

## 复现

```bash
python -m pokejev play --decider jev --version v4 --battles 50 --out runs/v4
python -m pokejev play --decider rule --battles 50 --out runs/rule
python -m pokejev eval runs/v4
```

上表使用的"固定队伍配对评测"工具位于本包所出自的研究仓库中；本包自带的命令行使用随机队伍。
