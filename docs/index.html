HOW IT WORKS工作原理

1

CODE COMPUTES代码计算

Damage, KO chance, type matchups and the opponent's best reply, for every legal move and switch.为每个合法招式和换人算出伤害、能否击倒、属性克制和对手的最佳回击。

2

JEV CHOOSESJEV 选择

It sees all the options at once and gives each one a probability.一次看到全部选项，给每个选项一个概率。

3

THE MOVE IS PLAYED执行招式

The top pick is played, and every decision is saved for the replay viewer.执行概率最高的选项，每次决策都保存下来，供回放查看。

STEER WITH ONE SENTENCE一句话操控

DESIGNER INTENT设计师意图Never use a move that lowers our own stats unless that move is likely to knock out the opponent.

No rule code: the sentence goes straight to Jev. In the video, the plain rule would pick Close Combat, which lowers our stats; Jev picks Triple Axel instead. 不用写规则代码，这句话直接交给 Jev。视频中，普通规则会选降低自身能力的近身战，而 Jev 改选了三旋击。

Works in Chinese too.中文意图同样有效。

GET STARTED快速开始

# 1. a local Pokémon Showdown server
git clone https://github.com/smogon/pokemon-showdown
cd pokemon-showdown && node pokemon-showdown start --no-security

# 2. this project (Python 3.10+)
pip install -r requirements.txt

# 3. a free practice battle + the viewer
python -m pokejev demo

# 4. real Jev (your TypeSafe key, ~$0.001/battle)
export TYPESAFE_API_KEY=...
python -m pokejev demo --real --intent ha02
